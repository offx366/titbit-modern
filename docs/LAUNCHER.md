# Лаунчер и моды

Лаунчер из экспериментальной ветки `widescreen-outpaint`. Графический пакет хранится в приватном R2-бакете и выдаётся после серверной проверки файлов игры. Прямой публичной ссылки на арт нет. Локальные установленные профили сохранены.

## Запуск

**Windows:** распакуйте комплект Widescreen и откройте `TitbitLauncher.exe`.

**Linux:** распакуйте комплект и выполните `./Launch.sh`. Требуются системные библиотеки игры; Python для упакованного лаунчера не нужен.

1. На вкладке **Файлы игры** выберите вашу установленную игру или импортируйте диск / ISO / IMG / CUE / CCD в отдельную папку. Проверяются 19 файлов версии 1.00 по SHA256.
2. На вкладке **Моды** выберите 16:9 или 16:10 и нажмите **Подтвердить файлы и скачать**. Сервер выдаст случайный запрос, лаунчер вычислит ответ по локальным файлам и получит одноразовый доступ к пакету. Скачиваются подготовленные дорисованные фоны; архив собирается локально.
3. На вкладке **Игра** выберите **Оригинал**, **Widescreen 16:9** или **Widescreen 16:10** и нажмите **Играть**.

Игра использует отдельные профили. Исходный `QUEST.ezd`, видео и сохранения в импортированной папке не перезаписываются. При первом запуске .sav копируются в профиль; дальнейшие сохранения независимы. После удаления мода резервный профиль с .sav остаётся в `saves/`, при переустановке они восстанавливаются.

| Платформа | Профили и резервные сохранения |
|---|---|
| Windows | `TitbitLauncher-data/` рядом с лаунчером |
| Linux | `${XDG_DATA_HOME:-~/.local/share}/titbit/launcher/` |

Для другого расположения: `TitbitLauncher.exe --data ПАПКА_ИГРЫ --store ПАПКА_ПРОФИЛЕЙ`. В Linux: `./titbit-tools launcher --data ПАПКА --engine ./titbit`.

## Пакет Widescreen

`Titbit-Widescreen-0.1.0.titbitmod` — ZIP с фиксированным manifest.json и 39 PNG: 38 локационных фонов и фон меню. Формат 16:10 получается центральным кадрированием тех же изображений. Музыки, видео, оригинальных архивов, текстурных атласов и исполняемых скриптов внутри нет. Маски, геометрия, исходные надписи меню и аудио читаются из локальной игры.

Поддерживается архив `QUEST.ezd` версии 1.00: SHA256 `bc214d2862997c27b7db627154dfcb31a526c789f364e9e7060c58522b9e03fb`. Проверка определяет совместимость данных; она не устанавливает права на копию игры. Локальные файлы и ISO на сервер не отправляются: передаётся только ответ на проверку.

В `config/mods.json` указан API шлюза, без секретов и прямых URL пакета. Содержимое ZIP и хеши проверяются до установки. Извлечения произвольных путей и запуска кода из пакета нет. Неудачная загрузка/сборка не публикует частичный профиль. Отмена во время сборки выполняется после текущего этапа. Одновременная запись двумя лаунчерами блокируется, во время игры профиль занят.

## Без интернета и резервная копия

Скачанный `.titbitmod` остаётся в `downloads/` каталога лаунчера. Сохраните его на другом носителе. Кнопка **Из .titbitmod…** устанавливает этот же пакет без сети, после проверки локальной копии игры. Установка 16:10 повторно использует уже загруженный пакет.

Старый открытый пакет удалён из GitHub Releases. После разрешённого скачивания локальная копия остаётся доступной для офлайн-установки. Проверка подтверждает доступ к байтам поддерживаемой игры, а не покупку или лицензию. Технические детали: [серверный протокол](../server/mod-gateway/README.md).

## Ограничения

Мод экспериментальный: 55 мировых сцен расширены; три сцены подвала остаются в 4:3, мини-игры и видео сохраняют исходный формат. Меню дорисовано отдельно. Сохранены исходная логика и известные ошибки оригинала. Загрузка всех сцен проверялась отдельно от полного сюжетного прохождения. Нужен движок из этого комплекта, старые релизы не поддерживают широкое меню.

## Из исходников

```powershell
python tools/titbit_launcher.py --data C:\Games\Titbit --engine build\modern\TitbitModern.exe
python tools/titbit_launcher.py --download-mod --source C:\Images\Titbit.iso --data C:\Games\Titbit --store build/profiles --ratio 16x9
python tools/titbit_mods.py install build/Titbit-Widescreen-0.1.0.titbitmod --data C:\Games\Titbit --store build/profiles --ratio 16x9
```

Для работы из исходников нужны Python 3.11+, Tk и Pillow. Упаковка Windows: `python tools/package_portable.py --game-build build/modern`; Linux: `sh linux-port/tools/build_tools.sh`. Арт и собранные архивы находятся только в игнорируемом `build/`, в git не добавляются.

При обрыве скачивания повторите проверку: токен одноразовый, частичный пакет не устанавливается. Если сервер временно недоступен, установленная игра и уже проверенный пакет в кэше работают без сети.
