# Ядерный Титбит

**Windows:** откройте `Titbit.exe`. **Linux:** выполните `./Launch.sh`.
Импорт, запуск, настройки, моды и Studio доступны в одном окне. Python и VC6 для готового комплекта не нужны.

## Первый запуск

1. Укажите папку вашей игры, CD или образ ISO / IMG / CUE / CCD. Старый установщик запускать не требуется.
2. Дождитесь импорта файлов.
3. Нажмите **Играть**.

Файлы служебных программ находятся в `bin/`. Запускать их отдельно не нужно.

## Моды

**Моды → Widescreen → Установить.** После установки мод включается автоматически. Галочка включает и отключает его; без включённых модов запускается оригинальная версия.

Widescreen расширяет локации, меню и обзор. Формат подбирается под монитор автоматически; отдельной настройки пропорций нет. Если выбран другой монитор, нужный вариант собирается из уже скачанного пакета. Сохранения Widescreen общие для всех форматов экрана.

Пакет выдаётся из приватного хранилища после проверки локальных файлов игры. Исходные файлы на сервер не отправляются. Проверка подтверждает доступ к поддерживаемым данным, а не покупку или лицензию. Скачанный пакет остаётся в `downloads/`; **Установить из файла…** позволяет использовать резервную копию без сети.

Список включённых модов хранится в `launcher.json` как `enabledMods`. Это список, а не выбор единственного режима. Сейчас доступен Widescreen; новые моды потребуют своих встроенных обработчиков. Произвольные ZIP и скрипты не исполняются; неизвестный мод не будет молча пропущен.

## Данные и сохранения

| | Windows | Linux |
|---|---|---|
| Данные лаунчера | `data/` рядом с `Titbit.exe` | `${XDG_DATA_HOME:-~/.local/share}/titbit/launcher/` |
| Импорт игры | `data/game/` | `${XDG_DATA_HOME:-~/.local/share}/titbit/game/` |

Старая папка `TitbitLauncher-data/`, если она есть, продолжает использоваться. Настройки старого лаунчера переносятся автоматически. Оригинальные ресурсы не перезаписываются. Исходная игра и мод имеют отдельные сохранения: при первом запуске существующие `.sav` копируются в профиль. Удаление мода оставляет резервную копию сохранений в `saves/`.

**Полный экран** и разрешение — во вкладке **Настройки**. Linux использует системное разрешение. В игре **Alt+Enter / F11** переключает окно и полный экран.

## Ограничения Widescreen

Экспериментальная ветка `widescreen-outpaint`. Расширены 55 мировых сцен и меню. Три согласованные сцены подвала, видео и мини-игры сохраняют исходный формат. Загрузка всех сцен проверена отдельно от полного сюжетного прохождения.

## Из исходников

```powershell
python tools/titbit_launcher.py --data C:\Games\Titbit --engine build\modern\TitbitModern.exe
```

Нужны Python 3.11+, Tk и Pillow. Упаковка инструментов Windows: `python tools/package_portable.py --game-build build/modern`; Linux: `sh linux-port/tools/build_tools.sh`. Для CLI проверки: `Titbit.exe --check --data ПАПКА`. Техническое описание закрытой выдачи — [mod-gateway](../server/mod-gateway/README.md).
