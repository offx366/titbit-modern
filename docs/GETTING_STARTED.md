# Как запустить игру

1. Распакуйте готовый комплект из [Releases](https://github.com/offx366/titbit-modern/releases).
2. Откройте **Titbit.exe** в Windows или **Launch.sh** в Linux.
3. При первом запуске выберите вашу папку игры, CD или образ ISO / IMG / CUE / CCD.
4. Дождитесь импорта и нажмите **Играть**.

**Моды → Widescreen → Установить** — необязательное расширение локаций и меню. Галочка включает и отключает мод. Пропорции экрана определяются автоматически.

Настройки экрана и кнопка **Открыть Studio** находятся в том же окне. Программы из `bin/` отдельно запускать не требуется. Для готового комплекта не нужны Python, VC6 и старый установщик игры.

Исходные ресурсы не входят в комплект. Импорт читает вашу копию напрямую; подключать ISO не требуется. Установщики произвольных репаков не поддерживаются: сначала установите такой репак в отдельную папку и укажите её как источник.

Оригинальные файлы сохраняются. Игра и Widescreen используют отдельные профили сохранений; удаление мода оставляет резервную копию `.sav`.

Подробности: [лаунчер и моды](LAUNCHER.md), [импорт ресурсов](ASSETS.md), [редактор](../editor/README.md).
