# Данные игры

Titbit Modern использует полные ресурсы вашей копии **«Ядерного Титбита»**.
Текстуры, модели, уровни, анимации, диалоги, музыка и озвучка сохраняются в
родном архиве **QUEST.ezd**; видеоролики — в отдельных AVI.

## Что откуда берётся

| В portable-пакете | Из вашей копии игры |
|---|---|
| Titbit.exe / Launch.sh — импорт, настройки, моды и запуск | QUEST.ezd — полный игровой архив |
| Движок в bin/ | 18 оригинальных AVI-роликов |
| Studio — локальный редактор, открывается из лаунчера | Сохранения — по желанию, отдельно |

**Оригинальный EXE не заменяет архив игры.** Его одного недостаточно для запуска.
Как перенести ресурсы из папки, CD или образа: [пошаговая инструкция](GETTING_STARTED.md).

## Что делает импорт

Поддерживается полный оригинальный набор версии 1.00: 19 файлов, 311 181 440 байт.
Список размеров и SHA256: [assets.json](../config/assets.json).

- Находит `QUEST.ezd` и ролики в установленной игре либо дистрибутиве с диска.
- Копирует нужные данные в выбранную папку Titbit Modern; исходник не изменяет.
- Проверяет файлы по контрольным суммам. Совпадающие файлы повторно не копирует,
  отличающиеся не перезаписывает молча.
- Не переносит установщики, старые EXE/DLL, кодеки и прочие программы с диска.
- Не копирует и не заменяет пользовательские сохранения.

Архив не нужно вручную распаковывать: игра и Studio читают его напрямую.
Ролики остаются в исходном формате; преобразование музыки, моделей и текстур
для обычной игры не требуется.

## Studio и моды

Studio читает исходный архив без записи. Изменения находятся в отдельном
проекте, а экспорт создаёт новую копию архива. Сначала проверяйте мод в отдельной
папке игры и храните исходный `QUEST.ezd` отдельно.

Экспортированный `QUEST.ezd` содержит и исходные ресурсы. Для публикации
своей работы делитесь собственными моделями, текстурами и изменениями проекта,
а не всем оригинальным архивом.
